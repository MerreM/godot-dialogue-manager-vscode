# Change Log

## 0.0.1

Initial release.

- `.dialogue` language support with syntax highlighting for cues, jumps, responses, conditions, mutations, random and concurrent lines, tags, line IDs, interpolation, inline conditions/mutations and BBCode.
- Outline and workspace symbols for cues.
- Go to definition, find references and rename for cues, including across files linked with `import "res://..." as name`.
- Completion for jump targets (`=> `), and character names (Ctrl+Space).
- Hover previews for jump targets.
- Diagnostics for unknown/duplicate/invalid cues, unknown import names and missing import files.
- Snippets for common constructs.
